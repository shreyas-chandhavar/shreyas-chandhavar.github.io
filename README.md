# Shreyas Engineering Portfolio

Static engineering portfolio website for Shreyas G. Chandhavar.

## Design intent
- Engineering case studies before generic skill lists
- Fast, responsive, dependency-free
- GitHub repositories as the technical evidence layer
- Requirements, verification and PLM/configuration-control evidence where relevant
- Visual language: premium engineering consultancy / technical editorial

## Current selected work
- **HART-120** — flexible high-aspect-ratio wing, aero-structural trades, load alleviation, system-mass accounting and robustness verification
- **FLEX-445** — public-benchmark hybrid flutter study using AGARD 445.6, DLM/p-k, passive-active control, ML screening and physics re-verification
- **NACA0012 Control-Surface Hinge** — MATLAB load modelling, SolidWorks CAD, contact FEA and analytical-to-FEA correlation
- **AeroStruct-15MW** — IEA 15-MW reduced-order aero-structural optimization with BEM, rotating-beam modelling, ML screening and physics re-verification
- **EROSHIELD-15** — IEA 15-MW leading-edge protection concept combining SolidWorks CAD, differential BEM screening, numerical audit and TurboPLM requirements/eBOM/ECR-ECN configuration control
- **Adjustable Lifting Fixture** — analytical sizing, SolidWorks CAD and preliminary FEA
- **Multi-Element WingSail CFD** — MSc thesis companion using OpenFOAM
- **Cantilever Beam Structural Analyzer** — MATLAB structural sizing and parametric study
